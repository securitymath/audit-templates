# Severity Classification

| Severity | Description | Examples |
|----------|-------------|----------|
| Critical | Direct fund loss without user interaction | Unauthorized withdrawal, oracle manipulation for instant profit |
| High | Conditional fund loss or significant disruption | Liquidation manipulation, governance hijack with flash loan |
| Medium | Indirect fund loss or limited impact | Rounding errors accumulating over time, missing slippage checks |
| Low | Best practices, gas, clarity | Unused variables, missing events, suboptimal data types |
| Informational | Suggestions and observations | Code style, documentation gaps, test coverage |
